# Sistema Acadêmico - Escola Crescer

Repositório técnico focado em backend, SQL e estrutura de pastas, desenvolvido para o **4º período de Engenharia de Software** como Projeto Integrador.

---

## Tecnologias

- **Node.js** — Runtime JavaScript para o servidor
- **Express** — Framework web para criação das rotas REST
- **MySQL** — Banco de dados relacional
